# Research Agent

LangGraph research agent that writes sourced reports, checks citations, and caps tool calls and page fetches.

A brief goes through one pass: normalise, plan, gather, fetch pages, write the report, check citations, then finish.

## What the code enforces

- Tool calls are capped at 12, and page fetches at 6.
- A citation URL that was not in the gathered pages fails the check.
- Fetches stay on public addresses, including every redirect. Pages are size-capped and limited to text or HTML.
- Golden briefs fail a report that misses an expected heading, cites fewer than three sources, or cites a URL that was not gathered.

Design notes, decisions, and the API contract are in [docs/](docs/).
# Research Agent  API service that turns a business research brief into a sourced, structured report. Built for internal automation (ops, strategy, RevOps) on:  | Layer | Stack | | --- | --- | | Language | Python 3.12+ | | Packaging | [uv](https://docs.astral.sh/uv/) | | Orchestration | LangGraph | | LLM | Any OpenAI-compatible provider via `LLM_BASE_URL` (OpenAI, Gemini, Groq, DeepSeek, OpenRouter) | | Search | Tavily | | HTTP API | FastAPI | | Database | PostgreSQL |  ## Capabilities  - Accept a research brief (topic, goals, constraints, audience, depth). - Authenticate `/v1` routes with an API key (`API_KEYS` in `.env` — a shared secret you set). - Plan searches, gather evidence via Tavily, synthesize a cited report with OpenAI. -
